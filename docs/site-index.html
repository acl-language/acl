ACL — Agent Communication Language

A compact, binary, platform-agnostic protocol for communication between autonomous AI agents: Ed25519-signed envelopes, speech-act performatives, a compiled content language with typed vocabularies, and transports from local pipes to WebSocket.

▶ Playground

Watch two real agents (argus, kenji) converse — every message is a signed envelope from an actual run, decoded live in your browser. Request → result, input_required → resume, content-language fact queries.
