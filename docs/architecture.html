ACL Agent Communication Architecture

Platform-agnostic binary protocol with semantic layer for autonomous agents

Security Guarantees

  • • Ed25519 signature on every envelope
  • • HKDF-SHA256 key derivation (never raw secrets)
  • • X25519 ECDH + ChaCha20-Poly1305 for sealed envelopes
  • • Session key derivation (per-channel)
  • • Batch signature verification

Semantic Layer

  • • 17 speech-act performatives
  • • Typed content language (facts, actions, commitments)
  • • Dialogue legality matrix (§16)
  • • FP/RE formal semantics per performative
  • • RDF/JSON-LD interop

Platform Agnosticism

  • • MessagePack binary wire format
  • • stdio, HTTP/SSE, WebSocket, relay transports
  • • Python (PyO3) and TypeScript (napi-rs) bindings
  • • MCP + A2A ecosystem bridges
  • • Independent implementation from spec alone

ACL — Agent Communication Language • Platform-agnostic binary protocol • Apache-2.0
